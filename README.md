# Radiant – site public

Page statique (GitHub Pages) qui parle directement à Supabase avec la clé publique.

## Mise en ligne
1. Ajoute `index.html` à la racine du dépôt `radiant-site`.
2. Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
3. Adresse : https://astriazyt.github.io/radiant-site/

## Supabase (une fois)
Authentication → URL Configuration :
- Site URL : https://astriazyt.github.io/radiant-site/
- Redirect URLs : https://astriazyt.github.io/radiant-site/

Aucun secret dans ce dépôt (seule la clé publique est utilisée).
